# DemoBuilder — fictional RAG fixture

These are invented example facts for automated tests, not Jagel policies.

## Paket dan masa uji coba

Semua paket memiliki masa uji coba 14 hari.

### Paket Bronze

Paket Bronze berharga USD 10 per bulan. Fitur Bronze mencakup driver dan voucher.

### Paket Silver

Semua fitur Paket Bronze.
Paket Silver menambahkan formulir pendaftaran dan laporan. Harga USD 20 per bulan.

### Paket Gold

Semua fitur Paket Bronze + Silver.
Paket Gold menambahkan aplikasi driver terpisah. Harga USD 30 per bulan.

### Paket Platinum

Semua fitur Paket Bronze + Silver + Gold.
Paket Platinum menambahkan white label. Harga USD 40 per bulan.

## Dukungan remote

Remote support gratis untuk Paket Platinum. Untuk paket lain, biaya demo USD 5 per sesi.

## Salah transfer

Proses refund ini hanya untuk pembayaran dengan kode unik yang salah. Tidak ada
kebijakan refund langganan umum, uptime SLA, atau data akun pelanggan dalam fixture.
